From this directory, run bun install, then bun run reproduce:plane.
This deliberately uses the pinned core bundle where the defect was observed,
not this repository checkout. Results record the baseline defect, not a fix.
The no-plane control solves; the intermediate-pour and physical-obstacle cases
fail. A production fix must keep the physical-obstacle case blocked and verify
actual antipads in an integration test. Coordinates are board-world mm, +X right,
+Y up, +Z above the board (right-handed); pad centers are points.

The standalone JavaScript reproduction uses its own pinned dependency version;
it does not typecheck against unrelated parent-workspace core declarations.
